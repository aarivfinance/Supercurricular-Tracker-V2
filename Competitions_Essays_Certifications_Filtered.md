# Competitions, Essays & Certifications — with reading paired to each one
### Only things with an actual competitive output or a real certificate. Reading is now a column in every row — not a separate list.

**Confidence key:** ✅ checked directly against the organisation's own page. ⚠️ secondary source only — verify yourself. **DROPPED** = checked and it's not real/current.

Reading format in each row: **Mainstream** book → **Niche** book (read the mainstream one first, the niche one is what you contrast it against in your personal statement).

## Other Competitions (non-essay)

|---|---|---|---|
